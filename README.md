# Claude Workflow Starter

An open-source starter kit for building AI workflows with the Anthropic Claude API.

## Features

- Prompt templates
- Conversation management
- Streaming examples
- Error handling
- Environment configuration
- Reusable utilities

## Installation

```bash
git clone https://github.com/pedroksilva/claude-workflow-starter.git
cd claude-workflow-starter
npm install
```

## Usage

Create a `.env` file:

```env
ANTHROPIC_API_KEY=your_api_key
```

Run:

```bash
npm start
```
